# PulseFit

PulseFit is a demo fitness center website developed using HTML, CSS, JavaScript and Bootstrap 5.

## Project Structure

```text
PulseFit/
|-- index.html
|-- about.html
|-- classes.html
|-- classesdetail.html
|-- schedule.html
|-- trainers.html
|-- membership.html
|-- contact.html
|-- assets/
|   |-- css/
|   |    |-- style.css
|   |-- js/
|   |    |-- script.js
|   |-- images/
|-- README.md
```

## How to Run

1. Download or clone the project.
2. Open the Pulsefit folder in VS Code.
3. Open index.html in a web browser or use the Live Server extension.
4. An internet connection is required to load Bootstrap from CDN.

## Dependencies

- HTML5 - Page structure.
- CSS3 - Custom styling.
- JavaScript - Interactive funcionality.
- Bootstrap 5.3.8 - Responsive layout and UI components.

## Asset Loading

- Bootstrap CSS and JavaScript are loaded via CDN.
- Custom CSS and JavaScript files are stored locally in the assets folder.
- Images will be stored locally in assets/images.
